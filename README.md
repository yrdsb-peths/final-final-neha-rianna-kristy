# Set up Greenfoot for VSCode

[Mac]
1. Open `Finder` and navigate to the Applications folder.
2. Right-click on the Greenfoot app and select `Show Package Contents`.
3. In the opened folder, go to `Contents -> Resources -> Java` and find the `greenfoot.jar` file.
4. Copy this `greenfoot.jar` to the `/lib` Folder in this project.

[Windows]
1. Open `File Explorer` and navigate to `C:\Program Files\Greenfoot` and locate the `greenfoot.jar` file.
2. Copy this `greenfoot.jar` to the `\lib` Folder in this project.

Our game is a snake game where the player's goal is to collect as many apples as they can to achieve a high score
To start playing, begin on the title screen, click the how to play to see the instructions, and then click select gamemode to choose the gameode.
- Bombs mode: avoid the bombs while collecting the apples
- Classic mode: Normal snake, just collect the apples
- Reverse mode: Like classic mode but the arrow keys do the opposite (ex. right goes left)
- Mega grid mode: Bigger grid size
- Small grid mode: Tiny grid size
- Fast: Snake speeds up every 5 seconds
